# SteamMachineFX-SLS2

A mod for Slay the Spire 2 which interfaces with my [SteamMachineFX service](https://github.com/JordanOsterberg/SteamMachineFX-Installer) to control the Steam Machine LED based on in-game health.

Requires installation of SteamMachineFX, see the link above.

## Installation

1. Unzip the SteamMachineFX.zip file (which can be downloaded from the GitHub releases) into `/home/deck/.steam/steam/steamapps/common/Slay the Spire 2/mods`.

You can now play the game and the LED strip should display your health.
